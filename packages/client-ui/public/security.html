2. Cryptographic Architecture & Mathematical Guarantees

Client-Side Key Custody & Zeroization

Private keys are generated locally via the W3C crypto.subtle standard as non-extractable handles. On logout or session termination, memory buffers are explicitly wiped with 0x00 (cryptographic memory zeroization).

Zero-Trust Serverless Storage

All direct messages, private Knowledge Vault documents, and media attachments are encrypted on the user's device using AES-256-GCM with 96-bit CSPRNG nonces before transmission. Cloudflare D1 and AWS S3 store only ciphertext bytes. Server operators cannot decrypt user data.

Zero-Knowledge Rate-Limiting (ZK-RLN)

Spam and DoS attacks are defended without harvesting personal data through Rate Limiting Nullifiers. Honest users remain cryptographically private; spammers attempting to exceed epoch thresholds reveal their nullifiers through polynomial intersection.

3. The 23 Continuous Production Security Gates

Every commit and deployment must pass all 23 automated production security gates (npm run audit:production):

  • Gate 1: Zero inline event handlers (100% action delegation).
  • Gate 2: Zero native dialogs (alert, confirm, prompt eliminated).
  • Gate 3: Strict Content Security Policy (Zero unsafe-inline scripts, frame-ancestors denied).
  • Gate 4: Volatile in-memory admin sessions (HMAC-SHA256, zero hardcoded tokens).
  • Gate 5: AES-GCM-256 non-extractable device vault (Zero plaintext seeds).
  • Gate 10: Verified volatile memory zeroization on logout.
  • Gate 15: Mandatory E2EE edge validation on all message payloads.
  • Gate 16: FIDO2 WebAuthn L3 hardware signature verification.
  • Gate 18: Distributed anti-DoS replay defense (10k bounded LRU nonces).
  • Gate 21: 100% CSPRNG entropy enforcement (Zero Math.random in cryptography).
